Golden set for the AI shaping feature. Ten messy requirement documents from invented domains
(no client material), each with expected areas, item count and a list of items that must not be
invented. The runner reports per spec: items found, items missed, items invented, wording that
changed meaning. Runs in CI on any change to a prompt file.

Files: specs/<01..10>-<domain>.md, expected/<01..10>.json, schema.json, run.ts (to be written in E4).
