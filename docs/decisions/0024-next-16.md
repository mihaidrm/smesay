# 0024 Next.js 16, 2026-10-01

Decided by Mihai in the Claude Code cloud session of 2026-10-01 ("16 for C"), on Claude's
recommendation.

1. The app runs on Next.js 16 (16.3.8 on the day). CLAUDE.md's stack line changes from 15 to
   16. The scaffold was created with create-next-app 15.5.27 and moved the same day, before
   any code depended on the version.
2. What 16 changes, from its upgrade guide (nextjs.org/docs/app/guides/upgrading/version-16):
   Node 20.9 or newer, TypeScript 5.1 or newer, Turbopack by default (no `--turbopack` flag),
   the ESLint CLI instead of `next lint`, `proxy` instead of `middleware`, request APIs
   (params, searchParams, cookies, headers) async only. Every later story is written against
   the 16 documentation.

Why: starting a build on a superseded major means a migration later, when it costs more.

Consequence: package.json, CLAUDE.md, docs/setup.md, docs/plan-steps.md updated; "Next.js 15"
added to docs/retired-terms.md.
