# 0015 Every design for desktop and phone, desktop first, 2026-10-01

Decided by Mihai in the Claude Code cloud session of 2026-10-01.

Every screen and page is designed twice: a desktop board (1440 wide) and a phone board (390
wide). The desktop board is drawn first, then the phone board, in the same pass. A design is not
done with only one.

Exception kept from CLAUDE.md: the respondent side is phone first, because respondents answer
on phones. It still gets a desktop board in the same pass.

Consequence: CLAUDE.md build rules updated. Landing page E already has both boards (step 1.1).
The respondent and PM prototypes get their second board as they are finished (steps 1.2, 1.3).
