# 0002 Clean design record, 2026-09-30

Decision: no file, export, screenshot, schema or note from any client engagement enters this
folder, the repository or any Claude session. The respondent instrument and the dashboard are
designed from the stories, public tools (survey builders, prioritisation boards, sourcing
platforms) and Mihai's own product judgement. Every design session writes a dated note in
docs/design-notes/ recording what was decided and why.

Why: Mihai's consulting agreement assigns materials and their concept produced during an
engagement to the client. The product is a general tool in a public category; the record shows
it was designed as one.

Consequence: design takes about a week longer; the record exists before the first screen exists.
