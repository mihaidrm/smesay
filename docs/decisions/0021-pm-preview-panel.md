# 0021 Live preview on every builder step, 2026-10-01

Decided by Mihai in a canvas comment on the PM app board, 2026-10-01 12:40: a preview of what
respondents see stays visible on every step, it highlights what the current step changes, and
it shows the desktop version by default, with a way to see the phone version too.

How it is built on the board (note 13), open to change:

1. A 460 px panel on the right of Import, Shape, Build and Share. Not on Results, Projects,
   Settings or the sample project: nothing there changes the instrument.
2. Desktop and Phone toggle, desktop first. The desktop preview is the respondent's 1000 px
   column drawn at 42 percent (14 px text reads at about 6 px). The phone preview is 390 px at
   true size. "Open full size" opens the respondent board for the chosen device.
3. A caption under the toggle says what the step changes, and the same parts carry a teal 300
   ring in the preview: Import rings the chapter row and the cards; Shape rings the card wording
   (reader version, or the original where rejected); Build rings the rating row, and the chapter
   row when the layout changes; Share rings the open and close note and shows the withdrawn page
   when the link is revoked.
4. The chapter pills in the preview are clickable, so the PM can look at any chapter or the
   About you page without leaving the step. Changing step resets the preview to its default.
5. To make room, the step screens use one column: the Import mapping, checks and file rows
   stack, the Share link card sits above the invites, and the old one-card preview on Build is
   gone. The sidebar stays at 240 px.

What this replaces: note 03 item 6 (a one-card preview on Build only).

Open: whether the 42 percent desktop preview is useful at that size, or whether the desktop
preview should instead reflow to the panel's width (one column of cards, readable text). Mihai
decides after clicking through.
