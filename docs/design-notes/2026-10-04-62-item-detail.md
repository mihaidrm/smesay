# Design note 62: the item detail panel, 2026-10-04

Made in the Claude Code cloud session of 2026-10-04 for stories/E8-5, under decision 0044.
The PM app board's item detail is the layout; this note records what was decided while
building it.

## What was decided

- The detail opens in place of the tab row and the tab, as the board draws it: Back to the
  tab (a secondary button, "Back to [tab name]") with the reference and area beside it, then
  a grid of the answers and a 360 px column, On this item, with the counts. The first build
  put it in a 560 px sheet fixed over the right of Results, as the story's technical notes
  named; the check found the sheet covered the project header, the tile chooser, the filter
  chips and the table's figures while they stayed in the tab order, so the board's layout
  replaced it (docs/review-list.md). The strip, the switch and the filter
  bar stay above, so the counts follow a filter change.
- The item is in the URL (item=[id]) beside the filter and the tab, so the detail is a link
  within the workspace. Back is a link to the same URL without the item; Escape inside the
  detail goes there too. The heading takes the focus when it opens; on the way back, within
  3 seconds of the close, the item's first link in the tab takes it again (in a register
  with two rows on the item, the first row's) (DetailShell and ReturnFocus in
  src/app/app/(shell)/projects/[projectId]/results/detail-shell.tsx).
- The item card: the reader text as the heading, Original under it when it differs, and
  Proposed with the value in a neutral pill. The answers are a table (Respondent, Answer,
  Reason, question or comment), as the board draws it, the answers first, then the people
  without one, each group by name.
- The pills (src/lib/results-detail.ts rowPill): the status pills for the four kinds
  (Different priority in the pushed back tint, decision 0044 item 6), the neutral pill for
  Rated, In progress, Not started and Not submitted, and the design system's absence pill
  for Not answered. A value shows only where it differs from the proposal; on an item with
  no proposal every value shows.
- On this item lists Agree, Different priority, Disagree, Unclear and Not yet answered, or
  Rated, Unclear and Not yet answered for an item with no proposal, whatever the instrument
  shows (the Agreement tab's rule per item). The numbers are mono and come from SQL.
- States: the panel skeleton while it loads, the Results banner in its place with Back
  beside it if it fails ("The item's detail could not load"), a line when the filter keeps no one who sees the
  item, and a line with Back when the item is not in the current version.
