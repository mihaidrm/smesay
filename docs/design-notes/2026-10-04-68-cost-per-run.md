# Design note 68: the cost of a run of Write actions, 2026-10-04

Made in the Claude Code cloud session of 2026-10-04 for stories/E9-3, under decision 0044.

## What was decided

- No line on the sample (its seeded runs count in no month). The last run is the last one the
  provider answered.
- One line under the actions: the project's last run of Write actions (its date, tokens in
  plus out, cost) and the workspace's AI spend this month. The spend is the same usage() sum
  that Settings' usage line now shows, so the two cannot differ. No budget number anywhere a
  workspace member sees (decision 0036).
- The estimate is the prompt and the output schema (which the API sends with it, the gap note 26
  named) at four characters a token, plus the output the caller expects.
  Write actions expects 1,500 tokens (eight actions of about 150 tokens and the JSON); Shape
  gives none, so its estimate keeps the whole allowance and errs high, as E4-1 chose. The
  output allowance of a run is unchanged (4,000 for actions).
- A run refused for the product cap or the workspace budget says what it would have cost in
  front of the refusal sentence.
- Whether the estimate lands within 30 percent of the actual cannot be shown without a real
  call (acceptance 3 amended). With 1,500 expected and 4,000 allowed, a run can spend about 2
  cents more than estimated; recorded in docs/review-list.md. Every answered run logs its estimate next to its actual, so the first real run answers
  it from the server log.
