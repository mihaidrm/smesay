# Design note 69: the CSV exports, 2026-10-04

Made in the Claude Code cloud session of 2026-10-04 for stories/E10-1, under decision 0044.
The PM app board's Export tab and design note 40 (every export takes the page's filter) are
the starting point.

## What was decided

- Four CSV files: Answers, Items with totals, People and Missing items, one card each, as
  E8-1's audit asked; the JSON and PDF exports come with E10-2 and E10-3.
- Each file is the page's view: the same filter and the same include-unsubmitted switch, read
  from the query string as the page reads it. A file is built from the very queries the page
  shows, so the reconciliation test adds the rows up to the page's numbers.
- Before the header: the watermark line on the sample, the filter in words when one is on,
  and a line saying the answers not submitted are included when the switch is on; with none of
  these the header is the first line, as RFC 4180 has it.
- A value is written as the scale's code with the instrument's label in the next column (two
  columns: value and label), so a file sorts by code and reads by label.
- Every field is quoted, lines end in CRLF, the file starts with the BOM, dates are ISO 8601
  with "+00:00" spelled out. A text cell that starts with =, +, -, @, a tab or a line break
  gets a single quote in front (OWASP, CSV Injection), since the PM opens these in Excel and
  a respondent on a public link types the comments.
- People, Answers and Missing items carry a Since submitting column with the Responses tab's
  mark (Changes not submitted again, Submitted again), so Status stays a count.
- Minutes to submit are whole minutes rounded in SQL, and the Median minutes tile is the
  median of those, so the file gives the tile back.
- The download is a link to a route under /api/projects/[id]/export/[file], fetched by the
  page so a failure shows the error copy; the file name is the project's name, the file and
  the date. The route streams the rows in chunks of 500 lines from a table built in memory.
  At the Team plan's 2,500 responses a month and 2,000 items that can be millions of answer
  rows; the memory it takes is not measured yet (docs/review-list.md). Every download writes an
  export_log row, with a text filter written as "[FIELD] contains a text" so no name or email
  is logged; a request another site starts gets 403 and writes no row.

## Components added

- ExportTab (results/export-tab.tsx): cards with the design system's card and secondary
  button. ExportDownload (results/export-download.tsx): the secondary button as a link, which
  reads Preparing the file while it waits and shows the error line in the unclear tint (as
  Shape's error) when the route fails.
